03 — Méthode avancée

Terminal avec yt-dlp

Pour TokyVideo, les playlists, ou la qualité maximale (4K/8K). yt-dlp gère plus de 1800 sites.

Installer yt-dlp (une seule fois)

Ouvre l'invite de commandes (Windows + R, tape cmd, Entrée) puis colle :

winget install yt-dlp

Pour fusionner l'audio et la vidéo, installe aussi FFmpeg :

winget install Gyan.FFmpeg

Ouvre Terminal (Cmd + Espace, tape Terminal) et colle :

brew install yt-dlp ffmpeg

Ouvre un terminal et colle :

sudo apt install -y yt-dlp ffmpeg

Fedora : sudo dnf install yt-dlp ffmpeg

Télécharger une vidéo

Dans le terminal, tape yt-dlp suivi de l'URL entre guillemets :

yt-dlp "URL_DE_LA_VIDEO"

Exemple concret avec TokyVideo :

yt-dlp "https://www.tokyvideo.com/fr/video/l-entorse"
Commandes utiles

Meilleure qualité possible :

yt-dlp -f "bestvideo+bestaudio" "URL"

Limiter à 1080p :

yt-dlp -f "bestvideo[height<=1080]+bestaudio" "URL"

Audio seul en MP3 :

yt-dlp -x --audio-format mp3 "URL"

Playlist complète :

yt-dlp "URL_PLAYLIST"

Vidéo protégée (cookies Chrome) :

yt-dlp --cookies-from-browser chrome "URL"

Mettre à jour yt-dlp :

yt-dlp -U
Note légale. yt-dlp est un outil open source légal. Utilise-le uniquement pour du contenu dont tu détiens les droits, ou pour un usage strictement personnel.
